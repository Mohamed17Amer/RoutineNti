اسم المشروع: My Creative Routine
النوع: تطبيق موبايل Flutter - إدارة مهام يومية (To-Do)

==================================================
أولاً: طلب العميل
==================================================

أنا طالب تطبيق مهام شخصي اسمه "My Creative Routine"، ألوانه أخضر وأبيض،
والفكرة إني أنظم بيه يومي ومهامي بشكل بسيط.

المرحلة دي عايزها UI كاملة ومتوصلة ببعضها، من غير backend،
والمهام تتخزن في الذاكرة بس لحد ما نربط API في المرحلة اللي بعدها.

المطلوب:

- Splash فيها اللوجو واسم التطبيق، ثانيتين وتدخل.
- شاشة "Let's Start" فيها صورة وجملة ترحيب وزرار يوديني على التسجيل.
- Register: صورة فوق وعليها "Pick Image"، و username و password و confirm password،
  والباسورد يبقى مخفي وفيه أيقونة أظهره بيها.
- Login: username و password ولينك "Don't Have An Account? Register".
- الرئيسية: صورة المستخدم و"Hello!" واسمه فوق، وتحتهم "Tasks" وجنبها عدد المهام.
  كل مهمة كارت أخضر فاتح فيه العنوان والوقت والوصف.
  ولو مفيش مهام تظهر صورة وجملة "There are no tasks yet".
  وزرار عائم أضيف بيه مهمة.
- Add Task: صورة، عنوان، وصف، اختيار المجموعة (Home / Personal / Work) كل واحدة بأيقونة ولون،
  ووقت الانتهاء بـ date picker.
- Edit Task: يظهر حالة المهمة (In Progress / Done)، أقدر أعدل كل حاجة،
  وفيه Mark as Done و Update و Delete فوق.
- لما أدوس على صورتي في الرئيسية تفتح البروفايل، وفيه 3 اختيارات:
  Profile (تعديل الاسم) - Change Password - Settings (اختيار اللغة AR / EN).

==================================================
ثانياً: اللي اتعمل (رد المبرمج)
==================================================

المرحلة الأولى اتسلمت، وكل الشاشات متوصلة ببعض:

1. Splash: Timer ثانيتين وبعدين pushReplacement على شاشة Let's Start،
   ومتأكد من mounted قبل التنقل.
2. Let's Start -> Register -> Login -> Home، كلهم بـ pushReplacement
   عشان المستخدم ميرجعش بالـ back لشاشات الدخول.
   التسجيل والدخول حالياً شكل بس (مفيش تحقق) لحد ما يتربطوا بالـ API.
3. Home:
   - فيه مهمتين تجريبيتين عشان الشاشة متبقاش فاضية في الديمو.
   - الكارت بيعرض أيقونة المجموعة بلونها، ولو المهمة خلصانة العنوان بيتشطب.
   - الضغط على الهيدر بيفتح البروفايل.
4. Add Task:
   - العنوان إجباري، لو فاضي بتظهر SnackBar.
   - وقت الانتهاء بيتاخد من date picker وبعده time picker،
     ويتكتب بالشكل dd/MM/yyyy مع الساعة. لو المستخدم مختارش وقت بيتكتب "Today".
   - الشاشة بترجع TaskModel جديد للرئيسية عن طريق Navigator.pop.
5. Edit Task:
   - Mark as Done بقى toggle (Done / In Progress) والنص اللي فوق بيتغير معاه.
   - Update بيرجع نسخة متعدلة من المهمة (copyWith) والرئيسية بتبدلها مكان القديمة.
   - Delete بيرجع 'delete' والرئيسية بتشيل المهمة من الليستة.
6. Profile: قائمة بـ 3 عناصر كل عنصر بيفتح شاشته.
   Change Password فيها 3 خانات كل واحدة ليها إظهار/إخفاء مستقل.
   Settings فيها toggle للغة (لسه شكل بس، الترجمة في المرحلة الجاية).

    home_screen/

تدفق البيانات:
الرئيسية هي اللي ماسكة الليستة. شاشة الإضافة والتعديل مش بيعدلوا في الليستة مباشرة،
بيرجعوا النتيجة بـ Navigator.pop (TaskModel أو 'delete') والرئيسية هي اللي تقرر وتعمل setState.

مفيش أي باكدجات خارجية غير cupertino_icons.

المرحلة الجاية:
- ربط التسجيل والدخول بالـ API وحفظ الـ token.
- حفظ المهام (API أو local database) بدل الذاكرة.
- اسم المستخدم وصورته من البروفايل بدل الاسم الثابت.
- تفعيل العربي والإنجليزي فعلياً من الإعدادات.
