==================================================
CLIENT REQUEST
==================================================

Hi, I need a personal tasks app called "My Creative Routine". Green and white colors,
and the idea is to organize my day and my tasks in a simple way.

The UI screens are already designed. What I need now is to connect everything to our backend
(I'm sending you the Postman collection, TODO.json) and make sure every form is validated.
Nothing should be static anymore.

What I need:

- Register: username, password, confirm password, and an optional profile picture
  ("Pick Image" at the top). Check the fields before sending: username at least 3 characters,
  password at least 6, and the two passwords must match.
- Login: username and password. If the user already logged in before, opening the app should
  take them straight to their tasks without logging in again.
- The access token expires quickly, so the app should renew it with the refresh token on its own.
  If that doesn't work, send the user back to Login with a clear message.
- Home: the user's real name and picture at the top, and their tasks from the server.
  Show a loader while loading, a message with "Try again" if something fails,
  and the empty state if there are no tasks. I want to pull down to refresh.
- Add Task: title and description are required, an optional image, the group
  (Home / Personal / Work), and an end date and time.
- Edit Task: edit everything including the image, mark it Done / In Progress, update, and delete
  (ask me before deleting).
- Profile: update my name and picture, change my password (old, new, confirm - the new one
  can't be the same as the old one), log out, and delete my account (with a confirmation).
- Any error from the server should appear as a readable message, not a crash or an empty screen.

==================================================
DELIVERY NOTE (DEVELOPER)
==================================================

The app is now fully connected to the API and every form is validated:

1. Register: optional image picked from the gallery and previewed at the top.
   Fields are validated as you type. If the server returns tokens, the user goes straight to Home;
   otherwise they're sent to Login with an "Account created" message.

2. Login: on success the tokens are saved on the device. Wrong credentials show the server's
   message. Next time the app opens, the splash screen checks for a saved session and opens Home.

3. Session: when a request fails because the access token expired, the app requests a new one
   with the refresh token and repeats the request automatically, so the user doesn't notice.
   If the refresh fails, the user is logged out and returned to Login with a message.

4. Home: shows the user's name and picture from the server, and their tasks with
   loading / error with "Try again" / empty states, plus pull to refresh.
   Tapping the header opens the profile.

5. Add Task: title and description are required (with length limits). The image is optional.
   Buttons show a loader while sending and can't be pressed twice.

6. Edit Task: all fields can be changed, including a new image. "Mark as Done" toggles the status,
   "Update" saves everything, and "Delete" asks for confirmation first.
   Note: the API only stores the title, description and image of a task, so the group,
   end time and Done status are saved on the phone for each task and stay after restarting the app.

7. Profile: loads the latest user data. "Profile" updates the name and/or picture.
   "Change Password" validates all three fields before sending. "Log Out" and "Delete Account"
   both ask for confirmation; deleting the account clears everything saved on the phone.

8. Errors: no internet, timeouts and server errors are all shown as short readable messages.

To run it, the API base URL needs to be set (it isn't included in the Postman collection).
